# q4n7x2

Experimental Geometry Dash editor tooling.

## Build

Windows builds are created with GitHub Actions.

Open **Actions → GD AI Editor - Windows → latest successful run** and download the `gd-ai-editor-windows` artifact.

## Local build

```powershell
.\scripts\build-geode.ps1
```

Python 3.11+ is used for the bundled backend.
